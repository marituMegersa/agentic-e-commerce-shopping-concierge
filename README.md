# Agentic AI E-Commerce Shopping Concierge 🤖🚀

Multi-agent personalized shopping assistant, price trend monitor, product comparison, and automated checkout agent.

## 🌟 Key Features
- **Agentic Multi-Agent Reasoning**: Specialised sub-agents orchestrating tools, memory, and external APIs.
- **Python FastAPI Backend**: Async REST API endpoints for agent trajectory execution and state tracking.
- **React Frontend Dashboard**: Modern interactive UI component suite for prompt input, real-time agent execution traces, and output visualization.

## 🛠️ Architecture & Tech Stack
- **Backend**: Python 3.12, FastAPI, Pydantic, Uvicorn
- **Frontend**: React 18, TypeScript, Lucide Icons
- **Domain**: E-Commerce & Retail

## 🚀 Quick Start

### 1. Run Python Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```
Backend API will run at `http://localhost:8000`.

### 2. Run React Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend app will run at `http://localhost:5173`.
